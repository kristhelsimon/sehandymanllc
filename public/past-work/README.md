# Past Work Images

Drag project photos into the matching service folder:

- `finish-carpentry`
- `electrical-lighting`
- `installations`
- `maintenance-repairs`
- `drywall-painting`
- `remodeling`

Use short, descriptive lowercase filenames separated by hyphens, for example:

- `custom-stair-railing-01.webp`
- `kitchen-lighting-upgrade-01.jpg`
- `bathroom-remodel-after-01.webp`

For before-and-after projects, use the same project name:

- `living-room-repair-before.jpg`
- `living-room-repair-after.jpg`

Recommended formats are `.webp` or optimized `.jpg`.
